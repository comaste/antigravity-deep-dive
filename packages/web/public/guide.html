DeepSearch — Notion & Box 横断検索システム

社内の Notion ワークスペースと Box クラウドストレージに散在するナレッジ・規程・議事録・仕様書を統合。 意味検索（Semantic） と 文字 Bi-gram キーワード検索 を Reciprocal Rank Fusion (RRF) で高精度に統合し、Gemini 3.8 Flash による根拠付き引用要約を提供します。

🎯 ハイブリッド RRF 検索
概念の曖昧検索と固有名詞・コードの厳密一致を同時に満たす最適スコアリング（$k=60$）。
🤖 Gemini 3.8 Flash 要約
検索ヒットした上位チャンクを文脈として注入し、参照番号付きで質問に的確に回答。
🔒 エンタープライズ安全設計
IAP (Identity-Aware Proxy) によるドメイン制限と 1Password / macOS Keychain / Secret Manager 連携。
🚀

クイックスタート（3ステップでローカル起動）

前提条件: macOS, pnpm, just, firebase-tools (Java 11+ for Emulator)。 わずか 3 つのコマンドでローカル開発環境が立ち上がります。

STEP 01

API シークレットを macOS Keychain へ同期

1Password CLI (op) を経由して Gemini API キーや Notion/Box トークンを取得し、macOS Keychain サービス dev.kexi.notion-box-search へ安全に格納します。

Terminal (fish / zsh) 
just sync-secrets
💡 1Password 未連携時のフォールバック
個別に API キーを設定する場合は just set-secret GEMINI_API_KEY "op://..." を実行するか、環境変数 GEMINI_API_KEY を直接設定して起動することも可能です。
STEP 02

ローカル Firestore Emulator を起動

ベクトル検索（findNearest）と複合インデックスをシミュレートするローカル Firestore Emulator（ポート 8080、UI: 4000）を立ち上げます。

Terminal (fish / zsh) 
just start-emulator
STEP 03

API & Web 開発サーバーの並列起動

バックエンド API（Hono on :3001）とフロントエンド Web（Vite on :5173）を同時に起動します。

Terminal (fish / zsh) 
just run-dev

ブラウザで http://localhost:5173 を開きます。 画面右上の緑色ボタン 「サンプルデータ投入 (Seed)」 をクリック（または別端末で just seed-data を実行）すると、Notion 規程集や Box 設計書などのデモチャンクが一括投入され、すぐに検索を体験できます。

🔍

画面別の使い方: 横断検索画面 (/)

日常の業務で社内ナレッジを探すメイン画面です。Google 検索のような直感的な操作性と、専門的な検索パラメータの調整を両立しています。

機能解説 01

自然言語クエリとキーワード検索の使い分け

入力欄に疑問文または単語を入力して Enter または検索ボタンを押します。

  • 自然言語の質問: 「リモートワーク手当の申請期限と上限額は？」「本番障害時のエスカレーション連絡網」など文脈を含む質問。
  • コード・用語検索: 「SLA-99.9」「SEC-004」「ISO27001」など記号や英数字を含む固有コード。
機能解説 02

検索モード（Mode）とソース絞り込み（Provider）

検索バー下のトグルボタンで即座に挙動を変更できます。

モード / フィルタ アルゴリズム 最適なユースケース
ハイブリッド (RRF) ⭐推奨 Vector ($k=60$) + Keyword ($k=60$) 通常利用。意味的近さと語彙一致を総合評価。
意味検索 (Semantic) 768次元 コサイン類似度 言い回しが思い出せない概念や類似規程の調査。
キーワード (Keyword) 文字 Bi-gram + カバレッジ再計算 特定のプロジェクトID・型番・担当者名のピンポイント検索。
ソース絞り込み Firestore 複合インデックス 「すべて」「Notion のみ」「Box のみ」をワンクリック切替。
機能解説 03

Gemini 3.8 Flash AI 回答と引用リンク

検索実行後、上部に紫色のグラデーション枠で AI 回答が表示されます。回答本文内の [1] [2] をクリックすると、その根拠となった下部の検索カードへスムーズにスクロールし、外部リンク（Notion ページまたは Box ファイル）を直接開くことができます。

機能解説 04

スコア内訳（Score Breakdown）の見方

各ドキュメントカードの「スコア内訳」を開くと、透明性の高い評価指標が確認できます:

  • RRF: 0.0328: Reciprocal Rank Fusion の合算スコア（高いほど上位）。
  • Semantic Rank: #1 (距離: 0.142): ベクトル空間上の近傍順位とコサイン距離。
  • Keyword Rank: #2 (一致率: 83%): Bi-gram トークン一致による順位。
  • マッチトークン: ドキュメント内で実際に合致した 2 文字トークン群。
⚙️

画面別の使い方: データソース・同期管理画面 (/admin)

Notion / Box の接続認証情報、インデックス同期の対象リソース（Database / Page / Folder）、および定期同期ジョブの実行ステータスを監視・操作する管理者向け画面です。

1. コネクタ接続ステータスの確認

Notion（Internal Integration Token NOTION_API_KEY または OAuth）および Box（Developer Token BOX_DEVELOPER_TOKEN または OAuth）の API 接続状況がカード形式で表示されます。未接続の場合はトークンを設定することで緑色の「接続済み (Active)」へ切り替わります。

2. 同期対象（Sync Targets）の追加・管理

同期対象カードの「対象を追加」から、インデックス対象を登録できます:

  • Notion: データベース ID（database）または 親ページ ID（page）。配下のページも再帰的に同期されます。
  • Box: フォルダ ID（folder）。ルートフォルダは 0 を指定します。
  • 有効/無効トグル: 一時的に同期対象から外したい場合、削除せずにスイッチを OFF にできます。

3. 手動同期（今すぐ同期）とジョブ履歴

「今すぐ同期を実行」ボタンを押すと、バックグラウンド同期ジョブがトリガーされ、Notion / Box からドキュメントを取得、チャンク分割、768次元ベクトル生成、Bi-gram 抽出を経て Firestore コレクションへ書き込まれます。画面下部の「同期ジョブ履歴」テーブルで、処理件数（Processed / Failed）や所要時間、エラーログをリアルタイムに確認できます。

🧠

ハイブリッド検索 (RRF) とアーキテクチャ設計

Elasticsearch などの外部クラスタを一切使わず、Cloud Firestore Native Mode 単体でエンタープライズ品質のハイブリッド検索を完結させています。

Semantic ベクトル検索 (findNearest)

gemini-embedding-001 で 768 次元の埋め込みを生成。Firestore Native の findNearest を利用して Cosine 距離による厳密近傍探索（Flat インデックス）を実行します。

Keyword 文字 Bi-gram + カバレッジ

日本語の形態素解析器の導入コストや辞書保守を排除し、NFKC 正規化文字 Bi-gram を採用。Firestore の array-contains-any (上限30件) で候補を取得後、アプリ層で全トークンの一致率を再計算します。

Fusion RRF ($k=60$)

尺度の異なる類似度スコアを直接足さず、順位の逆数で統合。片方でしかヒットしないレアな固有名詞や、語彙が一致しない抽象概念の双方が適切な重みで上位にランクインします。

Synthesis Gemini 3.8 Flash

最新の @google/genai SDK Interactions API を使用。上位チャンクをシステムプロンプトに注入し、ハルシネーションを極小化しながら引用バッジ付き回答を高速ストリーミングします。

開発コマンドリファレンス (justfile)

プロジェクトの全タスクは just タスクランナーで統一されています。

コマンド 実行内容と目的
just install-deps pnpm install を実行し、ワークスペース全パッケージの依存をインストール。
just sync-secrets 1Password から API キー（Gemini / Notion / Box）を取得し macOS Keychain へ同期。
just set-secret <KEY> <op://...> 特定の 1 つのシークレットを 1Password の参照先から macOS Keychain へ保存。
just start-emulator Firebase Firestore Emulator をポート 8080 で起動。
just run-dev Hono バックエンド（:3001）と Vite フロントエンド（:5173）を並列起動。
just seed-data ローカル Firestore Emulator にテスト用デモデータ（Notion / Box チャンク）を一括投入。
just run-test Vitest による単体テスト・検索ロジックテストを実行。
just check-types 全パッケージの TypeScript 型チェック（tsc --noEmit）を実行。
just lint-code 高速 Linter oxlint で静的解析を実行。
just format-code 高速 Formatter oxfmt でコードを自動整形。
just plan-infra Terraform の構文検証および実行計画のチェック（terraform validate）。

本番インフラ運用設計

infra/terraform/ 配下のコードにより、Google Cloud のマネージドサービスへセキュアにデプロイされます。

インフラ構成要素

  • Cloud Run (東京 asia-northeast1): フロントエンド SPA の配信および Hono API サーバーをホスティング。オートスケール対応。
  • Cloud IAP (Identity-Aware Proxy): Google Workspace (cureapp.jp) アカウントによる厳密な認証認可をエッジで強制。
  • Cloud Firestore (Native Mode): ドキュメント、チャンク、768次元 Flat ベクトルインデックス、および searchTokens 転置インデックス。
  • Secret Manager: 本番環境の Notion / Box OAuth クライアント情報および Gemini API キーの安全な保管。
  • Cloud Scheduler: 30分間隔（*/30 * * * *）で OIDC トークン認証付きで /api/sync/trigger を定期起動。
